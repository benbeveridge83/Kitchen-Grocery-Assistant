# Kitchen Grocery Assistant

A wall-mounted, voice-first household grocery and meal assistant.

## Planned capabilities

- Grocery inventory organized by refrigerator, freezer, and pantry
- Shopping list synchronized across devices
- Voice-first commands and camera-assisted item recognition
- Add purchases to inventory and remove consumed/discarded items
- Recipe library with ingredient requirements
- Meal-planning calendar that checks inventory and queues missing ingredients
- Household profiles and food/recipe preferences
- Cook Mode with linked recipe videos and hands-free playback controls
- Future Kroger / grocery ordering integration

## Architecture

The first version will be a tablet-friendly web/PWA frontend backed by Supabase. The design leaves room for an Android kiosk wrapper for reliable wake-word, motion, camera, and always-on behavior.
